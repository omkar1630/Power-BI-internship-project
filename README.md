# Power BI Internship - Cognifyz

This repository contains my completed Power BI internship project, including all 7 tasks focusing on data exploration, gender analysis, investment trends, and a comprehensive interactive dashboard.

## Tasks Completed
1. Data Exploration & Summary
2. Gender-based Analysis
3. Objective Analysis
4. Investment Duration & Frequency
5. Reasons for Investment
6. Source of Information
7. Combined Dashboard

## Key Insights
- Majority prefer mutual funds for capital appreciation.
- Investment monitoring frequency affects long-term growth.
- Most investors rely on online sources for investment information.
